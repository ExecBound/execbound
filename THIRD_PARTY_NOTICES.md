# Third-party notices

The licence texts and copyright notices of the third-party software an ExecBound release ships. Generated by `scripts/third_party_notices.py`; do not edit by hand. ExecBound's own licences are in `LICENSE` and in the `LICENSE` file of each directory licensed differently, and `DEPENDENCIES.md` explains why each Python distribution is here.

## psycopg and the LGPL

`psycopg` and `psycopg-binary` 3.3.6 are licensed under the GNU Lesser General Public License version 3 only. ExecBound imports them unmodified, as separately installed Python packages that a user may replace with any compatible build. Their complete source code is at <https://github.com/psycopg/psycopg/tree/3.3.6>.

`psycopg-binary` also bundles 15 native libraries: `libcom_err`, `libcrypt`, `libcrypto`, `libgssapi_krb5`, `libk5crypto`, `libkeyutils`, `libkrb5`, `libkrb5support`, `liblber`, `libldap`, `libpcre`, `libpq`, `libsasl2`, `libselinux`, `libssl`. Its wheel ships only its own licence, not theirs, so their texts are not reproduced here. They come from the PostgreSQL client library's own build; building `psycopg` against a system `libpq` instead would carry the operating system's copies.
