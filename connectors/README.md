# execbound-connectors

ExecBound's provider connectors, the Microsoft Graph connector and the mock connector client, and the mock vendor servers the tests, the demos and a Community install run. It depends on `execbound-protocol` and imports nothing from the server. Install the `mock` extra for the mock vendor servers.

Apache-2.0. The server that enforces the protocol is AGPL-3.0-only and lives in the same repository.
